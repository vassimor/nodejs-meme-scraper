### Node.js Meme Scraper

This is a project that demonstrates the HTTP request and response cycle, the Buffer form of data and the fs module of node.js.

The Cheerio library is also being used to parse the HTML string that comes back from the request.

MAIN GOAL

The mainn purpose of this project is to scrape the first 10 images of the following website: ttps://memegen-link-examples-upleveled.netlify.app/.

Once the images have been fetched , then a file called memes has to be created and the images have to be inserted in this folder.

The project uses the async / await functionality and a simple for loop, as well as the ArrayBuffer() and the Buffer.from() methods.
